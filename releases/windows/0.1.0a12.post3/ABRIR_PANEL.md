# Abrir PGOPCore

Extraé todos los archivos en una carpeta local nueva. En Windows con Python 3.14 disponible mediante `py`, abrí **pgop-panel.cmd**. La primera apertura prepara su propio entorno con las wheels incluidas. Las aperturas siguientes lo verifican y reutilizan. La carpeta desde la que abrís el panel se mantiene como carpeta inicial.

Usá **1–5** para cambiar de pestaña, **0/Esc** para volver, y **F1** para consultar la ayuda de la vista. En Archivos podés buscar un nombre parcial. Dentro de un archivo podés añadir una referencia al borrador. En Informes podés guardar el borrador y recuperar contextos tras reiniciar.

Si el entorno quedó incompleto o fue modificado, volvé a extraer este ZIP verificado en otra carpeta. La modalidad lineal sigue disponible con `pgop-panel.cmd --plain`. Las fuentes se abren en Windows con NTFS local.
