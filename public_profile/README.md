# Perfil público R1

Usá los comandos originales documentados en [herramientas](../docs/TOOLS.md).
El catálogo está en runtime/public_profile/CATALOG.json y vincula dos archivos
de agregados históricos ya autorizados. No contiene fuentes privadas originales.
La instalación se realiza con requirements.lock, sin redistribuir dependencias.
El [ejemplo](../examples/public-r1/README.md) genera un informe recuperable.
El manifiesto vigente de toda la distribución está en manifests/PUBLIC_SOURCE_MANIFEST.json.
