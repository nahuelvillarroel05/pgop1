# Static binding resolution V2 (opt-in)

`candidate.static_binding_v2.analyze_bundle(artifacts, catalog_sha256, alias_limit=4096)` consumes an existing independently verified E3 snapshot bundle. It reads pinned captured bytes only. It never imports target modules, discovers additional project paths, or changes V1/AST V2/Code-Only Claims/Context Engine/MCP. The six public MCP operations are unchanged. `tools/static_binding_v2.py --artifacts DIR --catalog-sha256 EXTERNAL_SHA` emits a canonical JSON report on stdout; no new custody/publication writer is introduced. The caller captures stdout as a new private artifact. No overwrite/ACK-publication guarantee is claimed for that caller action.

The new schema is `pgop1.static-binding-resolution.v2`, algorithm `explicit-module-reference-v2.0.2`. Each import alias has a `MODULE_REFERENCE` endpoint and a separate `object` projection. `from p.m import C as local` identifies the module spelling `p.m` and local alias spelling `local`; a match to selected `p/m.py` says nothing definitive about C, its exports, runtime binding or execution. `from p import m` references p; it never chooses p/m.py as the effective object. `from . import m` names the selected importing package, with m still only a candidate. Calls/inherits receive no new target binding. Existing lexical defines are not a binding gain.

`LOCAL_MODULE_MATCH` requires a direct unconditional module-body import, unique module identity, selected explicit package parents and COMPLETE source/target/parent ASTs. Parent module keys must also be unique: p.py together with p/__init__.py makes p ambiguous even when p/m.py is unique. Relative imports require one selected importer identity and cannot escape its package root. No namespace or sys.path precedence is inferred. Absolute imports still require the importer's selected complete package identity.

Source-wide hazards are intentionally conservative, including nested bodies, annotations/defaults/decorators: wildcard, global/nonlocal, any NamedExpr (including assignments in function defaults, class bases and comprehensions), reflective builtin identifier usage, any attribute store/delete, imports of sys/importlib/builtins (including aliases/from forms), or any source-wide __getattr__ definition, identifier, import alias or capture (including hooks under module-level control blocks). These hazards in the importer, target or a required package parent prevent a local match. They are a bounded syntactic policy, not an exhaustive detector of arbitrary runtime/environment mutation. Binding counts are module-owned, stop at nested function/class/lambda bodies and count imports, stores/deletes, definitions and captures; child parameters do not rebind module aliases. Repeated bindings and conditional/local imports abstain. No use-site flow analysis is claimed. Runtime shadowing can never be ruled out generally: the endpoint is explicitly a selected-source syntactic module reference. Version2.0.1 repaired an independently observed default-expression rebinding false match; version2.0.2 repairs two independently observed conditional-hook false matches. Initial failures and exposed replays remain separately recorded; replays are not fresh holdouts.

States are `UNRESOLVED` for RAW with no package structure; `OUTSIDE_SELECTED_UNIVERSE` for absent module/required package parent or missing importer identity (not proof of absence from the real project); `AMBIGUOUS` for collisions, hazards, relative escape or binding/control uncertainty; `INSUFFICIENT_EVIDENCE` for incomplete AST. `CANDIDATE_ONLY` is reserved for module endpoints and always used for the separate imported-object projection following a local module reference. It is not evidence of an object's origin. No object LOCAL_MODULE_MATCH exists in this version.

Rows bind exact source/target SHA-256, authorized paths, AST snapshot/scope IDs, statement and alias spans, alias occurrence index, declared alias/bound spelling, relative level, resolved module spelling, package parent pins, rule and universe identity. IDs include spans and alias index, so repeated names/duplicate bytes across paths stay distinct. A partial source's unavailable AST details use explicit UNKNOWN/null and never emit a local match. The universe identity covers mode/roots/ordered source pins; catalog identity additionally covers claims and authorized root. They are different identities by design.

At most32 sources/262144 bytes per source and existing AST V2 fixed budgets are inherited through E3 verification. COMPLETE trees are reparsed only to recover import alias spans and scope-owned binding facts. Strict integer alias_limit is1..4096; a deterministic captured-row prefix is emitted at the cap with PARTIAL, examined and omitted counts. total_import_aliases counts only captured AST import aliases, not invisible relations in omitted units. Coverage per source is retained, so zero observed rows in a partial source never proves absence. Reparse and independent verification share CPython AST, native Windows I/O and E3 verification limits, including no independent per-source verifier timeout or OS memory isolation; no stronger CPU/memory isolation is promised. Wall time is measured by the caller; peak memory is NOT_MEASURED.

`tools/verify_binding_v2.py --artifacts E3 --catalog-sha256 EXTERNAL_CATALOG_SHA --report REPORT --report-sha256 EXTERNAL_REPORT_SHA` verifies the report against independently recomputed V2 rows from the same pinned snapshots. It imports no V2 producer or semantic helpers. Shared pure serialization/schema, snapshot loader, CPython AST, independent E3 verifier and Windows provider are declared dependencies. Exact canonical bytes enforce types, ordering, IDs, spans, aliases, coverage and all target pins; coherent attacker rehashing does not replace the external catalog authorization anchor. The verifier never edits source/bundles/reports.

RAW and CODE_TREE must contain identical selected bytes. Compare E3 whole-import states and E4 typed-module states with this semantic difference explicit. A new real match requires demonstrable source/target pins and complete package evidence, not just a larger candidate list. Imported objects and all execution/causal links remain NOT_PROVEN. Source/artifact currency at ACK remains NOT_PROVEN; memory integration is DEFERRED. This finite experimental extension is neither general Python name resolution nor a security qualification.
